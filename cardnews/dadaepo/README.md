# 다대포 모션 카드뉴스

인스타그램 피드용 4:5 비율(1080×1350) 모션 카드뉴스 5장입니다. 모든 텍스트는 HTML에서 편집할 수 있고, 모션은 CSS와 JavaScript로 구성되어 있습니다.

## 미리보기

- 전체 재생: `index.html`
- 특정 카드: `index.html?card=3`
- 정지 최종 프레임: `index.html?card=3&static=1`
- 1080×1350 내보내기 화면: `index.html?card=3&static=1&export=1`

좌우 화살표 키로 카드를 이동하고, 스페이스바로 재생/일시정지를 전환할 수 있습니다.

## 편집 위치

- 문구·카드 구조: `index.html`
- 색상·타이포·레이아웃·모션: `styles.css`
- 자동 재생·카드 이동: `motion.js`
- 카드 기획안: `storyboard.yaml`
- 사진과 로고: `assets/`
- 최종 프레임 PNG: `previews/`
